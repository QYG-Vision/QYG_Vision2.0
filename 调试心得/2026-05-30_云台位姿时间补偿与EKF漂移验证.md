# 下一步做什么：2026-05-30 云台位姿时间补偿与 EKF 漂移验证

## 背景

当前现象：
- 装甲板静止，初始在摄像头画面上方。
- planner 满输出接管时，云台会先过冲，然后像正弦波一样上下震荡。
- EKF 建模出来的四框和红色目标框也会跟着上下震荡。
- 稳定时间可能需要数秒。
- 直接用小电脑通过串口给云台固定值时，云台本身转动稳定，不明显震荡。

其他学校同学建议关注两件事：
- EKF 参数 `Q` 是否合理。
- 云台位姿获取是否存在时间戳补偿问题。

本计划优先验证时间戳补偿，因为“静止目标 + 云台运动时模型忽飘”很像图像时间和云台姿态时间没有对齐。

## 核心原则

不要在一次运行中连续切换多个时间补偿值后，直接根据最终稳定状态判断哪个值最好。

原因：
- EKF 有历史状态。
- 中途切 offset 时，EKF 的状态已经被前几个 offset 影响过。
- 后面看到的稳定结果，可能是多个 offset 叠加后的结果，不能说明当前 offset 贡献最大。

正确方法是：每个 offset 独立冷启动，使用同一套指标评分。

## 调试工具状态

`QYG_sentry_debug.cpp` 中已经添加：
- `gimbal_pose_time_offset_ms`：当前云台位姿时间补偿值。
- `,`：offset 减 1ms。
- `.`：offset 加 1ms。
- `/`：恢复默认 `-1ms`。
- OpenCV 画面显示 `POSE offset=...ms`。
- VOFA/CSV 输出：
  - `gimbal_pose_time_offset_ms`
  - `pitch_loop_meas_pp_deg`
  - `pitch_loop_rx_pp_deg`
  - `ekf_speed_norm`
  - `ekf_abs_vz`
  - `ekf_abs_w`

按键调节只用于快速找方向，不用于最终定参。

## 实验一：快速找方向

目的：判断最佳 offset 大概在负方向、正方向，还是默认附近。

步骤：
1. 固定静止装甲板。
2. 运行 `QYG_sentry_debug`。
3. 进入自瞄，让 planner 接管，等 `gain=1.00`。
4. 从默认 `-1ms` 开始观察 3 到 5 秒。
5. 用 `,` 逐步测试 `-2ms, -3ms, -4ms...`。
6. 如果明显变差，用 `/` 回到 `-1ms`，再用 `.` 测试 `0ms, +1ms, +2ms...`。

观察项：
- 画面中四框和红框是否还上下飘。
- `rx_pp` 是否变小。
- `meas_pp` 是否变小。
- VOFA 中 `ekf_speed_norm`、`ekf_abs_vz`、`ekf_abs_w` 是否变小。

输出结果：
- 只记录一个粗略范围，例如 `-6ms` 附近可能更稳。
- 不把快速找方向的结果当作最终结论。

## 实验二：冷启动分段对比

目的：量化哪个 offset 真正更好。

候选值建议先粗扫：
```text
-10ms, -8ms, -6ms, -4ms, -2ms, -1ms, 0ms, +2ms, +4ms, +6ms, +8ms, +10ms
```

如果实验一发现某个区域更好，再细扫：
```text
例如 -8ms, -6ms, -4ms, -2ms, 0ms
```

每个 offset 必须独立执行：
1. 设置 offset。
2. 重新启动程序，或者至少重新进入自瞄，让 tracker/EKF 重新初始化。
3. 前 2 秒不计入结果，作为初始化时间。
4. 记录后 5 到 10 秒数据。
5. 对每个 offset 记录同样指标。

## 判断标准

一个好的 offset 应该同时满足：
- 每次冷启动都更快稳定。
- 稳定后 `pitch_loop_meas_pp_deg` 更小。
- 稳定后 `pitch_loop_rx_pp_deg` 更小。
- 静止装甲板时 `ekf_speed_norm` 更接近 0。
- 静止装甲板时 `ekf_abs_vz` 更接近 0。
- 静止装甲板时 `ekf_abs_w` 不异常跳动。
- 画面中 EKF 四框和红框不明显上下追逐。

如果某个 offset 只是在一次中途切换后看起来稳定，不能作为最终参数。

## 后续分支判断

如果某个 offset 明显优于默认 `-1ms`：
- 将该 offset 固化为新的默认值。
- 再用 planner 满输出测试静止装甲板和轻微移动装甲板。

如果所有 offset 差异都不明显：
- 时间补偿大概率不是主因。
- 下一步回到 EKF `Q/R`、planner 输出滤波、云台控制响应三个方向继续拆解。

如果 offset 能改善测量漂移，但云台仍然过冲：
- 时间补偿是问题之一。
- 还需要继续调 planner 输出斜率、pitch 限速或云台控制参数。
